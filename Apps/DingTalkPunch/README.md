# 钉钉定时打卡（小米 / Android）

一个轻量 Android 应用：在设定的时间自动打开钉钉，并可选「自动点击打卡按钮」。

## 功能
- 设置多个打卡时间（如 08:30、18:00、20:45）
- 到点自动打开钉钉（通过高优先级全屏通知，锁屏也能自动弹出钉钉）
- 可选「自动打卡」：开启无障碍服务后，自动点击钉钉里的“打卡 / 上班打卡 / 下班打卡”按钮
- 开机 / 重启后自动重新排程
- 内置小米 / Redmi（MIUI / HyperOS）专项设置入口

## 构建
需要 Android Studio（含 Android SDK 34）或命令行 Gradle。
1. 用 Android Studio 打开本目录（File → Open）。
2. 等待 Gradle 同步完成。
3. 菜单 Build → Build Bundle(s) / APK(s) → Build APK(s)。
4. 把 `app/build/outputs/apk/debug/app-debug.apk` 传到手机安装。
（命令行也可 `./gradlew assembleDebug`，需要本地 Gradle / AGP 环境；Android Studio 会自动下载。）

## 小米 / Redmi 必做设置（否则可能不触发）
1. 手机管家 → 应用管理 → 自启动：允许本应用自启动（或 App 内点「小米：自启动/后台设置」）。
2. 手机管家 → 电池与性能 → 省电策略：选「无限制」；并加入神隐模式白名单。
3. 权限 → 显示悬浮窗 / 锁屏显示：允许（让全屏通知能在锁屏弹出）。
4. 通知管理：允许通知，且设为「重要 / 全屏」。
5. 若开启自动打卡：设置 → 更多设置 → 无障碍 → 本应用，开启。
6. 设置 → 应用 → 本应用 → 其它权限 → 闹钟和提醒：授予「精确闹钟」。

## 使用
- 打开 App，点「添加打卡时间」选择时间，可添加多个。
- 点「保存并启用定时」。
- （可选）打开「自动打卡」开关，并去系统无障碍里启用本服务。
- 到点手机会自动弹出钉钉；若已开启自动打卡，则自动完成点击。
